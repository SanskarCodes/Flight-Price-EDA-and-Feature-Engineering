# Flight Price Analysis

## Project Overview

This project analyzes flight pricing data using Python and various data analysis libraries.

## Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

## Project Workflow

1. Data Cleaning

2. Feature Engineering

3. Exploratory Data Analysis

4. Data Visualization

## Key Insights

- Most flight prices lie between ₹3,000 and ₹15,000.

- Airline choice significantly affects pricing.

- Flight duration positively impacts ticket prices.

- More stops generally lead to higher fares.

- Total Stops and Duration are strong predictors of price.
